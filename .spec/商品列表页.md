# 商品列表页需求

## 列表页导航

添加一个第一级菜单的 Table，样式可参考 [](../apps/web-naive/src/views/demos/table/index.vue)，打开 Table 后需要将 Table 固定已有的 Tab 中，点解 Tab 可切换回该 Table。

## Table 内容

- Table 菜单名: 核价SKU
- titles 右边顶部有4个按钮，分别为: 改参, 改价, 保存, 提交
- titles 右边顶部需要有一个设置按钮，可以调整需要显示的列，拖动可改变列的顺序
- titles: 选中, SKU, 标题, 主图, 尺寸图, 商品图, 报价, 还价, 底价, 利润, 利润率, 二次报价, 长, 宽, 高

## titles 描述

- 选中: 多选框勾选列
- SKU, 标题: 文本
- 报价, 还价, 底价, 利润, 利润率, 二次报价, 长, 宽, 高: 数字. 其中双击击可修改: 二次报价, 长, 宽, 高
- 主图, 尺寸图: 单张图片，点击可放大预览
- 商品图: 多张图片，点击一次切换下一张图片，并且右上角标显示当前图片的顺序和总数量, 双击可放大预览当前图片

## 操作/功能需求

- 修改过（数据有变化）的列，保存前需要标黄提示
- 各个 titles 列需要支持

## 按钮描述

- 改参: 自动随机修改选中列的 长, 宽, 高
- 改价: 自动随机修改二次报价，但是需要在前端上限制不能低于底价
- 保存: 去掉所有多选框勾选，去掉标黄提示
- 推送: 显示5秒 loading 页面，loding 页面显示进度
